# UI/UX review — 2026-10-19

Scope: every surface of the app on `main` at `5bba3f9` (after v8.47 + #159–#164): status menu,
Welcome tour, popups/pill, Settings (9 tabs), Chat window. Method: screenshots of the running app
plus a full string/control inventory read from the SwiftUI code, judged against the macOS HIG and
Nielsen's heuristics (consistency, error prevention, recognition over recall, minimalism).

**Overall verdict.** The core loop (shortcut → speak → text) is simple. Everything around it has
grown by accretion: each feature added its own section, its own model picker, its own key hint
and its own wording. The result is a Settings window of ~110 controls and ~2,500 words of help
text, a chat with five ways to do most things, and three different names for half the features.
Nothing is broken in isolation; the confusion comes from volume and inconsistency.

Status column: **B1** = fixed in batch 1 (`fix/ux-review-batch1`), **ASK** = needs Magnus's call
(product/IA decision), **LATER** = clear but larger, queued.

## P1 — structure: too many places, too many choices

**11. Credentials are scattered over five tabs.** Google/xAI/Anthropic/OpenAI keys and OpenRouter
in General; OpenRouter again in Dictate; Google *account* (Calendar/Gmail) in Chat; custom chat
endpoint in Chat; self-hosted transcription endpoint in Dictate; local LLM server in Dictate
Prompt. Messages say "Sign in with Google" for Gemini, but there is no such control.
→ **One "Accounts" tab**: every key, OpenRouter, Google account, Trello, mail, and the three
custom endpoints, each with one status chip. Feature tabs then only *pick* a model. — ASK

**12. Chat tab is a second Settings window.** 20 sections, ~75 controls, ~1,000 words. Meeting
settings (transcription model, summary model, chunk interval, safeguard, flag shortcut, MCP) hide
under Chat → Advanced. → Split **Meetings** into its own tab; integrations (Google, Trello, Mail,
MCP) move to Accounts. Chat keeps model, prompt, commands, memory, folders. — ASK

**13. Model pickers offer everything.** Dictation shows 16–18 tiles; five Gemini Flash variants
(3.1 Flash-Lite, 3.5 Flash-Lite, 3.5 Flash, 3.7 Flash, 3.8 Flash) that a user cannot tell apart.
Chat shows ~18. → Curated top row (Recommended · Fastest · Offline) plus a "More models"
disclosure; drop superseded versions from the visible list as Chat already does via
`chatReplacement`. — ASK

**14. Missing-key behaviour differs per picker.** Dictate, Meeting Transcription and Read Aloud dim
tiles without a key (with no reason on the tile); Dictate Prompt, Chat, Meeting Summary and Smart
Improvement let you pick them and fail later. → One rule: selectable, tile shows "Needs key" and
links to Accounts. — LATER

**15. Every feature tab opens with "Keyboard Shortcut".** The shortcut is set once; the model and
prompt are what people come back for. About already lists all shortcuts read-only (and misses
"Add to Glossary"). → One editable Shortcuts section (General), one-line "Shortcut: ⌃⌥1 · Change"
in each feature tab at the bottom. Glossary row added to the overview now. — B1 (overview), ASK (move)

**16. Same block rendered several times.** The MLX "Available Models" block can appear 4× (Dictate
Prompt, Chat, Meeting Summary, Smart Improvement); "Close when clicking outside" appears twice with
the same label and opposite defaults; Popup settings are split between General top level and
General → Advanced. → Downloads in one place (Dictate → Offline models); window behaviour labels
name the window ("Close Settings when…", "Close Chat when…"). — LATER (labels B1)

**17. Jargon on the main path.** "Routed", "slug", "endpoint", "MLX", "conditioning", "224 tokens",
"Temperature 0.0 · verbatim … versions before 7.96", "(m)/(w)" voice genders. → Plain words on the
surface, the technical detail behind Advanced. — LATER

## P1 — onboarding

**18. Eight steps, decisions before value.** Privacy step has 2 toggles and 4 bullets before the
user has heard the app work; the key step offers six parallel paths (OpenRouter, four keys,
offline). → Step 2 becomes one question, "How should dictation run?": **Offline** (private, free,

toggle to the Done step. Target: 5 steps. — ASK
