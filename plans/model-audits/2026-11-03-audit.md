## Pareto check

### 1. Is any model we ship dominated?

**Yes, one: `gpt-4o-transcribe` is dominated by `gpt-transcribe`** (same provider):

| Axis | `gpt-transcribe` | `gpt-4o-transcribe` |
|---|---|---|
| Price | $0.0045/min | $0.006/min |
| Silence leaks | 0/9 | 9/9 |
| Glossary | 82% | 57% |
| Latency 1.3 / 8.2 / 21.3 s | 637 / 825 / 1207 | 709 / 972 / 1602 |
| Lifecycle | current | shuts down 2027-02-26 |

Last month 4o won the short clip (645 vs 673 ms). It no longer does: the max of the
gpt-transcribe 1.3 s run (933 ms) overlaps, but the medians and the 21.3 s gap (395 ms, no range
overlap) are on gpt-transcribe's side.

The only argument left in `TranscriptionModels.swift:93` is that 4o follows instructions in
`prompt`. That axis is not measured beyond glossary, and on glossary 4o loses by 25 points. A
model that pastes invented text 9 times out of 9 fails the workflow's first criterion anyway.
Filed as `model-migration`: hide it from the dictation picker and forward stored selections.

**Dominated on today's run, held one month: `gemini-3.8-flash` as a *dictation* model, by
`gemini-3.1-flash-lite`.**

- 3.1 FL is cheaper: $0.50 audio / $1.50 vs $0.75 / $3.75.
- Leaks: 6/9 vs 8/9.
- Glossary: tied at 71%.
- 3.1 FL is faster at all three lengths, with no range overlap: 1053 vs 2588 ms.
- Context is the same.

Decision: no proposal this month. Rule applied: a single run reversed October's 17-point glossary
lead for 3.8 (76% vs 59%). The latency gap is one month old and may be Google's 3.7→3.8
rerouting. What would reverse it: if the 2026-12 run again has 3.8 tied or behind on glossary and
slower, hide it from dictation. Chat is unaffected either way.

**Checked, not dominated:**

- `gpt-4o-mini-transcribe`: cheapest OpenAI STT, and faster than gpt-transcribe at 8.2 s and 21.3 s.
- 3.1 vs 3.5 Flash-Lite: prices cross on audio input vs output, and so do the latencies.
- `gemini-3.1-pro-preview` vs `gemini-4-argon`: Argon is cheaper on output only until
  2026-11-30. From Dec 1 it costs $4/$20 vs $2/$12, and Argon's speed is unmeasured.
- `gpt-5.4-mini` vs the new `gpt-6.1-terra`: Terra's input price is higher ($1 vs $0.75).
- `gpt-6-sol` vs `gpt-6.1-sol`: unchanged since October (6.1 is slower and rejects `none`).
- `grok-4.3` vs `grok-4.7`: they cross.
- Haiku / Sonnet / Opus 5.5: a price ladder.
- Nano Banana 2.1 vs 3 Pro Image, and 3.8 FL TTS vs 3.8 Flash TTS: they cross.

### 2. Is any model missing that should be there?

- **`gemini-3.5-transcribe`: yes.** It was measured serving, with 0/9 leaks in two consecutive
  months. The workflow ranks silence first, so it should be the Gemini-only fallback.
  - Cost of following that rule: glossary 71% → 41% (65% with +vocab, but that is a different
    API at ~2.4 s), and +330 ms on 1.3 s clips. It is faster at 8.2 s (1060 vs 1159) and
    21.3 s (1335 vs 1449).
  - The measurement wins. Filed as a proposal.

  Luna and Sol. It accepts `none`, so `/think minimal` works, and it has web search, which
  matches the owner's research-not-coding rule. **It has not served a request in the
  measurements**, so this audit cannot recommend it.
- **`gpt-live-transcribe`: not a gap for batch Dictate**, because it is realtime-only. It may
  matter for the new *Dictate Live* (`3894d771`). Investigate further.
