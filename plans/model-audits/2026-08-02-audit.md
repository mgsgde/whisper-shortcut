## Pareto check

Domination = better-or-equal on **every** axis (price in, price out, quality, speed, context) and
strictly better on one.

### Gemini

| Model | In / Out | Ctx | Measured quality | Measured speed |
|---|---|---|---|---|
| 3.1 Flash-Lite | $0.50 audio / $1.50 | 1M | 94% gloss, 6/9 leak | 1599/1234/1653 |
| 3.5 Flash-Lite | $0.30 audio / $2.50 | 1M | 94% gloss, 9/9 leak | 2478/2937/4863 |
| 3.5 Flash | $1.50 / $9.00 | 1M | 94% gloss, 9/9 leak | 1692/1311/1515 |
| 3.6 Flash | $1.50 / $7.50 | 1M | 96% gloss, 6/9 leak | 2590/3285/5514 |
| 3.1 Pro | $2.00 / $12.00 | 1M | *not measured* | *not measured* |

- **3.1 vs 3.5 Flash-Lite:** prices cross ($0.50 vs $0.30 audio in; $1.50 vs $2.50 out). Neither dominated. 3.1 also wins on speed and silence.
- **3.5 vs 3.6 Flash:** 3.6 ties on input, is $1.50 cheaper on output, ties on context, and edges glossary — it would dominate 3.5 **except that 3.5 Flash is measured 1.5–3.6× faster on audio.** Speed is a Pareto axis, so both stay. *Caveat: speed was only measured on transcription; for text chat the axis is unmeasured, so the chat-side question is genuinely open.*

## Open questions

1. **Do you want an Anthropic key in `.env`?** Without it, four `PromptModel` cases are unguarded by
   the audit loop, and the one genuine Pareto prune this month (`claude-opus-4-8` → `claude-opus-5`)
   cannot be actioned. This is the single biggest blind spot in this report.
2. **Should the transcription default become key-conditional?** `gpt-transcribe` is measurably better
   on every axis but needs an OpenAI key and drops Dictation-prompt instructions. A conditional
   default ("use gpt-transcribe when an OpenAI key is present") is more code than a constant change —
   is that complexity worth it, or is flipping `isRecommended` enough?
3. **Is the Gemini silence-hallucination rate acceptable?** Every Gemini tier leaks 6–9 of 9 invented
   transcripts past the app's gates while all three non-Gemini cloud models leak zero. That points at
   the *gates* as much as the models — worth a separate look at `TextProcessingUtility` rather than
   a model swap.
4. **Should the benchmark be fixed to read the live container?** This run fell back to a snapshot
   glossary. Until that is fixed, glossary percentages are not directly comparable month to month.
5. **`gemini-3.1-pro-preview` has never been benchmarked.** Add it to the script's `MODELS`, or drop
   it from the transcription picker — offering an unmeasured model for dictation is a gap either way.
